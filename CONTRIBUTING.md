# Contributing to ai-logmon

We welcome contributions to ai-logmon! Please follow these guidelines to ensure a smooth and successful contribution process.

## PR Workflow

1. Fork the repository
2. Create a new branch for your feature or bug fix
3. Make your changes and commit them
4. Open a pull request against the main branch

## Commit Standards

* Use descriptive commit messages
* Follow the standard commit format: `fix: <brief description>` or `feat: <brief description>`

## Code Style Rules

* Follow PEP 8 guidelines
* Use consistent indentation and spacing

## Code Reviews

* All code changes must be reviewed by at least one maintainer
* Use GitHub's code review feature to provide feedback and approve changes
